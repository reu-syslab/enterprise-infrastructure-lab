# Operational documentation responsibility

Own future manual build records, maintenance procedures and recovery runbooks. Capture prerequisites, approved scope, expected results, verification, abort criteria and rollback before executing a change. Use [runbook-template.md](runbook-template.md). No executable steps are provided in this phase.

Keep raw outputs and private backups external. Link public-safe architecture/ADR references and describe sanitized evidence. A filled runbook must distinguish planned steps from observed execution.
