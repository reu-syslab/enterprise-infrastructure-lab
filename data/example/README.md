# Synthetic examples

`architecture.example.json` illustrates status labels, roles and candidate networks for reviewers. It is documentation data, not a Terraform variable file, Ansible inventory or deployable configuration. Field names are provisional documentation fields, not an approved automation schema.

Existing VLAN roles are confirmed; every subnet is invented for publication. Candidate VLAN IDs and `corp.example.test` remain unapproved examples. Gateway addresses, device hostnames, credentials, MACs, serials and real mappings are deliberately absent. Legacy alternate VLAN40 is represented separately so it cannot be mistaken for a new VLAN140.
